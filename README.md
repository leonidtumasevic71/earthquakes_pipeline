# Earthquakes Pipeline

## Описание проекта

ELT-пайплайн для сбора и обработки данных о землетрясениях с использованием USGS API.

Проект позволяет получать данные из API, сохранять исходные данные в RustFS, проверять их, удалять дубликаты и записи с пропущенными значениями, а затем загружать обработанные данные в PostgreSQL.

Для автоматизации процесса используется Apache Airflow, для визуализации данных — Grafana.

## Технологический стек

- Python — обработка и валидация данных.
- SQL — работа с базой данных.
- Apache Airflow — оркестрация пайплайна.
- RustFS — хранение исходных и обработанных данных.
- PostgreSQL — хранение обработанных данных.
- Grafana — визуализация данных.
- Docker Compose — запуск сервисов.
- pytest — тестирование Python-кода.

## Архитектура

```text
USGS API
    |
    v
RustFS (RAW data)
    |
    v
Извлечение и валидация данных
    |
    v
Очистка и удаление дубликатов
    |
    v
RustFS (Processed data)
    |
    v
PostgreSQL
    |
    v
Grafana

Apache Airflow — управление выполнением задач
```

## Как работает пайплайн

1. Проверяется доступность необходимых хранилищ и таблицы PostgreSQL.
2. Полученные из USGS API данные сохраняются в RustFS в исходном виде.
3. Исходные данные извлекаются из RustFS и проходят проверку структуры и значений.
4. Выполняется очистка данных и удаление дубликатов.
5. Обработанные данные сохраняются в RustFS.
6. Данные загружаются в таблицу `earthquakes` в PostgreSQL.
7. Grafana используется для визуализации данных из PostgreSQL.

DAG pipeline_dag настроен на запуск каждые 30 минут. Для задач предусмотрены повторные попытки при ошибках.

## Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/leonidtumasevic71/earthquakes_pipeline.git
cd earthquakes_pipeline
```

### 2. Настройка окружения

Создайте файл `.env` на основе шаблона:

```bash
cp .env.example .env
```

Заполните необходимые переменные окружения. Они используются для настройки подключений к PostgreSQL, RustFS и Apache Airflow, а также для указания API.

Не публикуйте реальные пароли и секретные ключи в репозитории.

### 3. Запуск проекта

Выполните команду:

```bash
docker compose up -d --build
```

### 4. Проверка состояния контейнеров

```bash
docker compose ps
```

Для просмотра логов используйте:

```bash
docker compose logs -f
```

## Доступ к сервисам

После успешного запуска сервисы доступны по следующим адресам:

- Airflow: http://localhost:8080
- Grafana: http://localhost:3000
- RustFS Console: http://localhost:9001

Для входа в сервисы используйте соответствующие учётные данные из конфигурации проекта.

В Airflow найдите DAG `pipeline_dag` и включите его, если он находится на паузе.

## Тестирование

Для запуска автоматизированных тестов используется pytest:

```bash
python -m pytest tests/ -v
```

Команда предполагает наличие каталога `tests/` и установленных зависимостей Python.

## Остановка проекта

Для остановки контейнеров выполните:

```bash
docker compose down
```

Именованные Docker volumes сохраняют данные между обычными остановками и повторными запусками контейнеров.
